About ChunkScout

ChunkScout is an independent collection of free Minecraft tools. It started as a seed map for finding biomes, structures and slime chunks, and grew into a toolbox for everyday building, travelling and server admin.

How the tools work

Every tool runs in your browser. The seed map recreates the game’s world-generation maths in JavaScript. Calculators like the Nether portal calculator use the same formulas the game uses. Nothing you type is sent to our servers.

Accuracy

We test the seed map against the game and other reference tools, and we say so on the page when a result might differ in-game. If you find something wrong, please tell us, ideally with the seed, edition, version and coordinates.

What’s next

More tools are on the way, including sphere and shape generators, an enchantment planner, an XP calculator, redstone calculators, player lookups and server utilities. We only publish data we can actually source, and we never present estimates or sample data as live statistics.
