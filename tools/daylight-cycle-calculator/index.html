How the Minecraft day works

A full day–night cycle is 24,000 game ticks. At the normal 20 ticks per second that’s 20 real minutes. Tick 0 is 6:00 in the morning, 6,000 is noon, 12,000 is roughly sunset and 18,000 is midnight.

TicksClockWhat happens
006:00Sunrise ends; /time set day uses 1000
600012:00Noon (/time set noon)
1254218:32Beds can be used (clear weather)
1300019:00/time set night; hostile mobs start spawning on the surface
1800000:00Midnight (/time set midnight)
2346005:28Beds stop working; mobs stop spawning soon after

Exact spawn timings depend on light level and weather; this table is for clear weather in Java Edition.
