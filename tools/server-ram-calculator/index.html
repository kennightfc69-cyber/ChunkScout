How this estimate works

This is a rule-of-thumb starting point, not a measurement. It starts from a base amount for the server type, then adds memory per player (scaled by view distance, since each player keeps chunks loaded) and per plugin or mod.

base (Paper 1.5 GB · modded 3 GB · large pack 5 GB)
+ players × (0.06–0.1 GB) × view distance ÷ 10
+ plugins/mods × (0.02–0.04 GB)

Real usage depends heavily on farms, entities, world size and specific mods. Start with the recommendation, watch memory with a tool like spark, and adjust. More RAM isn’t always better: very large heaps can cause longer garbage-collection pauses.
