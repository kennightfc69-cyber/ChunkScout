    How anvil costs work

    Every time you combine two things in an anvil (Java Edition), the cost in levels is:

    cost = penalty(left) + penalty(right) + value of what’s on the right
    penalty(n uses) = 2ⁿ − 1 → 0, 1, 3, 7, 15, 31…
    value = for each enchantment on the right: final level × multiplier

    The result has one more anvil use than whichever input had more. In survival, any step costing 40 levels or more is refused as “Too Expensive!”.

    Why the order matters

    Adding books one at a time onto the item makes the item’s penalty double every step, so the last books get very expensive. Combining books with each other first, in pairs, keeps every piece’s penalty low. Expensive enchantments (like Mending, Silk Touch or Thorns) should be in the right slot as few times as possible. This calculator tries every possible combination order and picks the cheapest one that never hits Too Expensive.

    FAQ

    Does this work for Bedrock?

    Not exactly. Bedrock calculates some anvil costs differently, so use the results as a guide only. The order advice (pair books first, expensive enchantments as few times as possible) still helps.

    Why do I need more levels than the total cost?

    Each step needs you to have at least that many levels at the time. Because higher levels cost more points, you spend fewer XP points by doing expensive steps at a low level and refilling in between. The “XP points” figure assumes you start each step with exactly the levels it costs.

    Can I fix “Too Expensive” on an item I already made?

    No. Prior work penalty never goes down. Use a new item, or grindstone it (which removes enchantments and resets the penalty) and start again in a good order.
