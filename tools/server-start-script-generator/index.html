Server Start Script Generator

Build a start.bat or start.sh with tuned JVM flags, the right RAM and optional auto-restart.

Java Edition servers (Vanilla, Paper, Fabric, Forge)Last updated 2026-11-19Runs in your browser

How to use the start script

  1. Put the script in the same folder as your server jar.
  2. Windows: save as start.bat and double-click it. Linux/macOS: save as start.sh, run chmod +x start.sh, then ./start.sh.
  3. The first run creates eula.txt. Set eula=true after reading the Minecraft EULA, then start again.

About Aikar’s flags

Aikar’s flags tune Java’s G1 garbage collector for Minecraft’s memory pattern and are recommended by the Paper project. Setting -Xms and -Xmx to the same value avoids the heap resizing during play. Leave 1–2 GB for the operating system, and more if other programs run on the same machine.

Recent Minecraft versions need a recent Java version (Java 21 for 1.20.5 and newer). If the server won’t start, check your Java version with java -version.
