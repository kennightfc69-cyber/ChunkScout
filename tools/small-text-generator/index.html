Where small text works

Small caps are ordinary Unicode letters, not a Minecraft font, so they work anywhere text is shown: tab lists, scoreboards, item names, signs, chat and server MOTDs, on both Java and Bedrock.

A few letters have no small-cap version in Unicode (for example x), so they stay as normal lowercase. Numbers and symbols aren’t changed. Some fonts and older devices may show missing characters as boxes.
