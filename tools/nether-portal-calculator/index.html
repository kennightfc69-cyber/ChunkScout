    How Nether portal coordinates work

    Every block you walk in the Nether counts as 8 blocks in the Overworld, but only on the horizontal X and Z axes. That’s why the Nether is so useful for fast travel: a 1,000-block trip in the Overworld is only 125 blocks in the Nether.

    Overworld → Nether: X ÷ 8, Z ÷ 8, Y unchanged
    Nether → Overworld: X × 8, Z × 8, Y unchanged

    Height (Y) is not scaled. The calculator keeps Y between 8 and 122 for Nether portals so the portal fits under the Nether’s bedrock ceiling.

    How to link two portals reliably

    1. Stand where your Overworld portal is (or will be) and note its X, Y and Z.
    2. Enter those numbers above with Overworld → Nether selected.
    3. Travel through the portal, then build a new portal frame at exactly the calculated Nether coordinates, even if the game already generated one nearby.
    4. Walk through both portals once in each direction to check they link to each other.

    Building at the exact converted spot matters because when you go through a portal, the game looks for the nearest existing portal around the converted position and only creates a new one if it can’t find any. Use Save this calculation to keep a list of your portal pairs on this device.

    Negative coordinates

    Minecraft rounds block positions down, toward negative infinity, not toward zero. So Overworld X = −100 becomes −100 ÷ 8 = −12.5, which is block −13 in the Nether, not −12. The calculator does this for you.

    Why a portal links to the wrong place

    • Two portals are close together in one dimension. In Java Edition the game searches roughly 128 blocks around the target in the Overworld and about 16 blocks in the Nether, so two Overworld portals less than ~128 blocks apart can end up sharing one Nether portal.
    • The Nether portal wasn’t built at the exact coordinates. Rebuild it at the calculated spot and break the auto-generated one if it’s in the way.
    • Bedrock Edition uses a similar but not identical search, so stay within a few blocks of the exact numbers on Bedrock.

    FAQ

    Does the Y level need to match?

    No. Y isn’t scaled, and the portal search covers the full height of the world, so you can put the Nether portal at any safe height. Keeping a similar Y just makes it easier to find.

    Does this work for Bedrock and Java?

    Yes. The 8:1 ratio is the same in both editions.

    Where are my saved calculations stored?

    Only in your browser’s local storage on this device. Nothing is sent to ChunkScout.
