A color code resets bold/italic/underline, so put formatting codes after the color: &a&lBold green, not &l&aBold green.

& vs §, and Java vs Bedrock vs servers

  • § (section sign) is what the game itself reads. Use it in server.properties MOTDs (written as \u00A7 in some setups), signs and books via commands, and Bedrock chat.
  • & is a plugin convention (EssentialsX, LuckPerms and most Spigot/Paper plugins translate & to §). Vanilla Java chat doesn’t accept either from players.
  • Hex colors (&#RRGGBB, MiniMessage) need Java 1.16+ and plugin support. Bedrock doesn’t support hex colors.
  • Bedrock adds extra codes such as §g (Minecoin gold) and a set of material colors. On Bedrock, §m and §n are colors, not strikethrough and underline, which Bedrock doesn’t have.
  • Vanilla Java commands like /tellraw and /title use JSON text components ({"text":"Hi","color":"green","bold":true}) instead of codes.
