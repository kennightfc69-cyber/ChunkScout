Block Gradient Generator

Pick colors with a wheel or sliders and get a matching gradient of Minecraft blocks. Load your own game’s textures for exact colors.

Block colors: built-in approximations

Load the official block textures from your own Minecraft for exact colors and real block pictures. The file is read on your device and never uploaded.

Where is my Minecraft .jar?

Open the versions folder inside your Minecraft folder and pick the newest version’s .jar:
Windows: %appdata%\.minecraft\versions
macOS: ~/Library/Application Support/minecraft/versions
Linux: ~/.minecraft/versions
Any resource pack .zip works too.

    How the gradient is made

    Pick a start and end color with the wheel, the sliders, a hex code or any block. ChunkScout blends between them in OKLab, a color space where equal steps look equally different to the eye. For each step it picks the block whose average color is closest, using only the block groups you tick. With Don’t repeat blocks on, each block appears once, and a step takes the next-closest unused block.

    Using your own Minecraft textures

    Built in, ChunkScout knows approximate colors for about 150 full blocks. For exact results, load the official textures from your own game: choose your Minecraft version’s .jar file, or a resource pack .zip. ChunkScout reads the block textures straight from that file in your browser, works out each block’s true average color, and shows the real textures in your palette. Nothing is uploaded. The textures are saved in your browser so you only do this once, and Forget textures removes them.

    With textures loaded you can also tick All other full blocks to use every solid block in your version, including ores, mossy and cracked variants, and blocks added in newer updates. Loading a resource pack builds gradients that match that pack.

    Tips for block gradients

    • Concrete and wool give the strongest colors. Terracotta, stone and wood give softer, more natural blends.
    • Use more steps for long walls and fewer for small builds. Five to eight steps is a good start.
    • Patterned blocks (logs, bricks) look smoother from a distance than up close, so check the textures before you build.
