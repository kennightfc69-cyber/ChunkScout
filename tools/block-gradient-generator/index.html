    How the gradient is made

    ChunkScout blends from your start color to your end color in OKLab, a color space where equal steps look equally different to the eye. For each step it picks the block whose average color is closest, using only the block groups you tick. With Don’t repeat blocks on, each block appears once, and a step takes the next-closest unused block.

    Tips for block gradients

    • Concrete and wool give the strongest colors. Terracotta, stone and wood give softer, more natural blends.
    • Use more steps for long walls and fewer for small builds. Five to eight steps is a good start.
    • Gradients across textured blocks (logs, stone bricks) look smoother from a distance than up close.

    How accurate are the colors?

    Each block is represented by one approximate average color of its default texture. Real textures have patterns and multiple colors, so two blocks with similar averages can still look different side by side. Treat the palette as a starting point.
