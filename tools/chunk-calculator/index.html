Chunks and region files

A chunk is a 16 × 16 column of blocks. To find the chunk, divide the block X and Z by 16 and round down. Rounding down matters for negative numbers: block X = −1 is in chunk −1, not chunk 0, and sits at position 15 inside it. Java Edition saves chunks in region files of 32 × 32 chunks (512 × 512 blocks), named r.X.Z.mca in the world’s region folder.

chunk X = floor(block X ÷ 16) region X = floor(chunk X ÷ 32)

Slime chunks

About 1 in 10 chunks is a slime chunk, where slimes can spawn below Y = 40 in any light level. In Java Edition which chunks are slime chunks depends on the world seed. In Bedrock Edition they’re the same in every world, so no seed is needed. The calculation here uses the game’s own formulas, the same ones as the seed map.
