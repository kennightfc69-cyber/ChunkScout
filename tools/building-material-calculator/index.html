How the estimate works

  • Walls are a ring around the outside: (length × width − inside length × inside width) × total wall height, where the inside is the size minus the wall thickness on each side. Doors (1×2) and windows are cut out of the walls.
  • Corner pillars replace the wall blocks at the four corners for the full height, so they’re listed separately.
  • Floors cover the inside area once per storey (the ground floor and each upper floor).
  • Roofs count one block or stair per roof square seen from above, including the overhang. A gable roof also adds the triangular gable walls at both ends, built from the wall material.
  • Solid fills the whole inside with the wall material, for things like pillars, statues or foundations.

Real builds often add trim, stairs, slabs and decoration, so treat this as the main blocks you need and add 10% or so for mistakes.

Planning tips

  • Odd widths (like 11) give a neat single-block ridge on gable roofs.
  • Use the stack calculator to plan storage for several materials, and the shape generator for round towers.
